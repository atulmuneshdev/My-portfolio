# 🚀 Modern Full Stack Developer Portfolio

A premium, high-performance portfolio website built with **React.js**, **Tailwind CSS**, and **Framer Motion**. This portfolio is designed to showcase professional background, engineering mindset, and developer identity with a futuristic aesthetic.

## ✨ Features

- **Futuristic UI/UX**: Clean dark theme with premium glassmorphism effects and modern typography (**Sora** & **Inter**).
- **Interactive Hero Section**: Dynamic typing animations, 3D parallax profile card, and floating tech badges.
- **Tech Identity**: A dedicated section showcasing the modern tech stack with interactive icons.
- **Performance Optimized**: 
  - GPU-accelerated animations using `will-change`.
  - Memoized particles and optimized blur effects for smooth scrolling.
  - Efficient asset management and local fallback for textures.
- **Fully Responsive**: Seamlessly transitions across Mobile, Tablet, and Desktop devices.
- **Bento Grid Layout**: Modern layout for technical expertise and availability status.
- **Smooth Navigation**: Framer Motion-powered page transitions and scroll indicators.

## 🛠️ Tech Stack

- **Frontend**: React.js 19
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion 12
- **Icons**: Lucide React, React Icons
- **Routing**: React Router Dom 7
- **Notifications**: React Hot Toast
- **Build Tool**: Vite 8

## 📁 Project Structure

```text
src/
├── components/       # Reusable UI components (Hero, TechStack, Background, Footer, etc.)
├── pages/            # Page-level components (Home, About, Projects, Contact, etc.)
├── assets/           # Static assets (images, svgs)
├── App.jsx           # Main application routing and layout
└── index.css         # Global styles and Tailwind configuration
```

## 🚀 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
